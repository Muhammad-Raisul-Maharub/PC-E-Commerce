## 3. Recommended Action Plan for Codebase UI Implementation

Per user confirmation under `/grill-me`, we will perform **Direct UI Replacement** across the web app.

### Replacement Guidelines:
1. **Catalog Filter Labels:**
   - Replace `"Socket"` with `"Motherboard Fit"`
   - Replace `"Form Factor"` with `"Board / Case Size"`
   - Replace `"TDP"` with `"Power Draw & Heat"`
   - Replace `"ECC Only"` with `"Crash-Proof Memory Only"`
2. **Product Detail Page (PDP) Specs Grid:**
   - Replace technical labels with clear plain English (e.g. `Power & Heat Output (120W)` instead of `TDP: 120W`, `Physical Size (ATX)` instead of `Form Factor: ATX`).
3. **PC Builder Telemetry & Slots:**
   - Replace `"BOM Breakdown"` with `"Itemized Parts List"`
   - Replace `"Thermal Delta ΔC"` with `"Cooling Headroom & Load Temp"`
   - Replace `"Actuation Force"` with `"Key Press Stiffness"`
4. **Checkout & Header:**
   - Replace `"EMI Available"` with `"Monthly Installment Plans from ৳..."`
   - Replace `"B2B Procurement"` with `"Corporate & Company Invoicing"`
   - Replace `"SKU"` with `"Item Code"`
